# Contributing

Hey! 👋 Alde here.

First of all, thanks for stopping by!

Whether you're here to fix a typo, squash a bug, redesign something, or accidentally discover a bug while trying to do something completely unrelated... welcome.

This project is maintained by the Fitrah Tribune team, and I'd love to keep the codebase nice and readable for future contributors (and my future self, because I'll probably forget what I wrote six months from now).

---

## Before you start

If you're planning a **big** feature or redesign, please open an Issue first.

Not because I don't trust you.

Mostly because I'd rather avoid two people spending three hours implementing the same thing.

---

## Branches

Please don't commit directly to `main`.

Create a branch with a descriptive name.

Good examples:

```text
feature/article-search

feature/dark-mode

fix/mobile-navbar

docs/update-readme
```

Not-so-good examples:

```text
new

test

realfinal

aaaa

pleasework
```

(We've all been there.)

---

## Keep things readable

If you write code that makes you think:

> "What on earth does this do?"

Future-you is probably going to think the same thing.

Use meaningful names.

Good:

```text
latestArticles

featuredNews

articleCard
```

Not so good:

```text
a

temp

thing

thing2

thing_final_final
```

Please don't make me play detective. 🔍

---

## Small Pull Requests > Giant Pull Requests

If possible, keep each PR focused on one thing.

Good:

* Fix mobile navbar
* Add search
* Improve article page

Less fun:

* Rewrite the entire website
* Change every file
* "Trust me bro"

Small PRs are easier to review and much less scary.

---

## Test your changes

Before opening a Pull Request, make sure the project actually runs.

If you changed something...

* Does it build?
* Does it look right?
* Did you accidentally break something else?

If yes...

👍 Awesome.

---

## Be nice

Everyone starts somewhere.

Questions are welcome.

Ideas are welcome.

Constructive feedback is welcome.

Being rude isn't.

Let's build cool stuff together.

---

## One last thing...

This project is open source, but that doesn't mean it's a free-for-all.

Please respect the project's direction, coding style, and other contributors.

If you're unsure about something, just ask.

I'd much rather answer a question than spend two hours untangling a mysterious Pull Request.



---

Happy coding! 🚀

Alde
